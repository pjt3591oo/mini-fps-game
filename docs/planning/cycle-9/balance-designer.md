### 2-2. 강화 비용

기대 시도 횟수 = 실패마다 +10%p 보정을 넣은 값. 최악 = 확률이 100%가 될 때까지 계속 실패한 경우. 도달 웨이브 = 그 웨이브를 클리어한 시점의 누적 수입이 누적 기대 비용 이상.

- 누적 기대 비용이 1~5웨이브 누적 수입(85 / 189 / 328 / 515 / 882)과 거의 정확히 겹친다. 강화만 사면 5웨이브까지 **웨이브마다 한 단계**씩 오른다.
- 운에 따른 편차(4만 판 모의, 수입은 기대값): +3 도달 웨이브 10% / 50% / 90% 지점 = 3 / 3 / 4, +5 = 5 / 5 / 7, +7 = 8 / 10 / 12. 최악 누적 비용은 7,010이지만 +7이 12웨이브를 넘기는 판은 10% 미만이다.
- +7 한 번 실패의 손실 420은 11웨이브 한 판 수입(381)보다 크다. 체감 손실은 크지만 보정 덕에 기대 시도 2.06회에 그친다.

지배 관계

1. **응급 처치 < 기다리기.** 솔로에서 상점을 열면 다음 웨이브 타이머가 멈추지만(`shopFreezesTimer`) 게임은 계속 돌아 자연 회복이 진행된다. 체력 1로 클리어해도 상점에서 17.3초면 가득 찬다. 협동은 웨이브 사이가 20초라 역시 가득 찬다. 상점 없이도 10초 대기 중 +30이 들어온다. 45크레딧이 사는 것은 최대 17초의 시간뿐이다.
2. **폭격 요청 < 수류탄 2개(거의 지배).** 28% 가격으로 합계 피해가 더 크다(460 대 420). 폭격만의 장점은 사거리 70m, 수류탄 한도(4개)와 별도 보유, 넓은 처치 반경(8웨이브 병사 기준 6.5m 대 3.8m)이다. 중장갑은 1~2웨이브(380 / 407)에만 중심에서 잡히고 3웨이브(433)부터 못 잡는다. 보스에게는 5 / 10웨이브 체력의 10% / 6%로, +4 소총 1.0초 분량이다.
3. 구급 주사와 방어막은 서로 지배하지 않는다. 방어막은 근접 다수에게 1.6배 효율이고 "현재 체력보다 큰 한 방"을 버티게 하지만, 포격대장전에서는 주사보다 못하다. **유지.**

보스 체력 = 기본 × `hpMulForWave` × (1 + 0.4 × (웨이브/5 − 1)). 강화 단계는 2-3의 기대 단계. 시간은 소총 전부 명중 기준(몸통 / 머리, 보스 머리 배율 0.5 적용).

봇의 한계

- 포격을 피하지 못한다. 10웨이브 결과는 사람보다 불리하게 나온다.
- 소총 강화를 살 수 없을 때마다 구급 주사를 2개까지 채우므로 강화가 2-3의 표보다 늦다. 주사는 체력 40 미만에서만 쓴다.

### 안 1 — 폭격 요청 피해 상향

- 문제와 근거: 2-4의 지배 관계 2. 크레딧당 피해 3.0 대 11.5, 3웨이브부터 중장갑을 못 잡는다.
- 바꿀 수치: `public/js/config.js` · `ITEMS.strike.dmg` · 420 → **600**

| 항목 | 현재 | 제안 |
| --- | --- | --- |
| 크레딧당 피해 | 3.0 | 4.3 (수류탄의 37%) |
| 중장갑 중심 처치 | 2웨이브까지 | 9웨이브까지(593) |
| 병사 처치 반경 8 / 12 / 15웨이브 | 6.5 / 5.8 / 5.3m | 7.0 / 7.0 / 6.7m |
| 5 / 10웨이브 보스 체력 대비 | 10% / 6% | 15% / 9% |

- 기대 효과: "중장갑이 낀 무리를 통째로 지우는" 고유 역할이 생긴다. 크레딧당 피해는 여전히 수류탄보다 낮아 수류탄을 대체하지 않는다.
- 위험: 피해 증폭 보급품과 겹치면 1,200이다. 2개(280)를 보스에게 쓰면 5웨이브 보스의 29%. 자기 피해(50)는 그대로다.
- 확인할 지표: 판 기록의 폭격 사용 횟수(`G.used.strike`), 폭격 1회당 처치 수, 보스 웨이브에서의 사용 비율. 사용이 여전히 0에 가까우면 다음에는 가격(140 → 100)을 본다.

### 안 2 — 응급 처치 가격 하향

- 문제와 근거: 2-4의 지배 관계 1. 무료로 같은 결과를 얻는 데 최대 17.3초면 된다.
- 바꿀 수치: `public/js/config.js` · `SUPPLIES.heal.price` · 45 → **20**
- 기대 효과: "기다리기 싫을 때 내는 값"으로 자리가 정해진다. 체력 40 이하로 클리어하면 크레딧당 체력 1.75 이상으로 구급 주사(1.0)보다 싸다. 대신 전투 중에는 쓸 수 없어 주사를 대체하지 않는다.
- 위험: 수치로는 지배 관계가 사라지지 않는다(0이 아닌 한 기다리기가 항상 더 싸다). 근본 원인은 상점을 연 동안 자연 회복이 도는 구조이고, 이는 시스템 기획자·개발 쪽 판단 사항이다.
- 확인할 지표: 응급 처치 구매 횟수, 솔로에서 상점을 연 채 머문 평균 시간(10초를 넘는 판의 비율).

### 안 3 — 강화 비용·확률 유지, 첫 보스 체력 하향안 철회

- 근거: 2-2, 2-3. 화력 우위는 최대 1.27배이고 12웨이브부터 줄어든다. 사이클 8이 걱정한 "피해 +70%로 후반 난도 붕괴"는 강화만으로는 일어나지 않는다. 지금 비용을 올리면 5웨이브 보스 처치 시간이 다시 늘어 "보스 근접" 사망이 늘 수 있다.
- 바꿀 수치: 없음(`UPGRADE.cost`, `UPGRADE.chance`, `UPGRADE.pity` 그대로). `ENEMY_TYPES.boss.hp` 3,200 → 2,800(사이클 7 안 3, 보류 중)은 **철회**한다. 강화가 같은 방향으로 더 큰 폭(−35%)을 이미 냈다.
- 위험: 봇 6판과 계산만으로 내린 판정이다. 사람이 강화를 얼마나 사는지는 모른다.
- 확인할 지표: 판 기록의 5 / 10웨이브 도달 시 소총 강화 단계, 5웨이브 사망 비율(봇 6판 중 1판), 10웨이브 보스전 소요 시간.

## 5. 조정안에 넣지 않은 관찰

- **후반 위험은 소모품 재구매다.** 11~15웨이브 수입은 웨이브당 평균 436인데, 구급 주사 3개 + 방어막 2개를 매 웨이브 다시 채우는 값이 360이다. 적 피해는 웨이브로 오르지 않으므로 소총 +7 이후에는 매 웨이브 실효 체력 280 + 방어막 12초로 들어갈 수 있다. 사람 데이터가 없어 조정안으로 내지 않았다. 다음 후보: `ITEMS.medkit.max` 3 → 2.
- **보스 소환병이 크레딧을 준다.** 보스를 살려 두면 14초마다 돌격병 3마리(36), 포격대장은 12초마다 사수 2마리(30)로 분당 약 150크레딧이 끝없이 나온다. 정상 진행(6웨이브 기준 분당 약 300)보다 느리지만 상한이 없고 점수도 함께 쌓인다. 수치가 아니라 판정 문제라 시스템·개발 쪽 확인이 필요하다.
- 소총 한 길: 강화 비용이 무기 공통이라 기본 화력이 높은 소총에 쓰는 것이 항상 이득이다(2-3). 무기별 비용 차등은 축이 하나 더 생기는 큰 변경이라 이번에는 내지 않는다.
- 보스 근접(35 피해, 사거리 3.4m)은 봇 5웨이브 사망 원인으로 두 사이클 연속 나왔다. 사람 플레이 기록이 생기면 먼저 볼 대상이다.

## 6. 미검증

- `data/runs.jsonl`이 아직 없다. 사람 플레이 기록이 한 판도 쌓이지 않아 구매 패턴, 보급품 줍기 비율, 사망 원인 분포를 읽지 못했다.
- 포격을 사람이 피할 수 있는지(사이클 5), 보급품이 언덕을 떠나게 하는지(사이클 3)는 이번에도 다루지 못했다.
- 쉬움·어려움 난이도의 수입(적 수 0.8배 / 1.25배가 처치 크레딧에 그대로 반영됨), 협동의 개인별 수입 격차, 변이 웨이브, 특성(강화 탄환 +15% 등)과 강화의 중첩은 계산하지 않았다.
- 2-1의 보스 웨이브 수입은 소환 2회를 가정했다. 보스전이 길면 더 많다.
