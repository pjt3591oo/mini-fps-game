# 사이클 12 기획안 — UX 기획자

주제: 성장 2단계, 보관함(인벤토리)과 선택지. 총괄 초안 C-4 "화면"을 실제로 만들 수 있는 수준까지 구체화한다.

담는 물건의 종류, 드롭 확률, 해금 특성의 수치는 총괄 초안과 시스템·밸런스 기획자가 정한다. 이 안은 **어디에 무엇을 어떤 문구로 보여 주는지, 어떤 키로 움직이는지, 무엇을 화면에서 빼는지**를 정한다. 문구 속 물건 이름은 예시다.

확인한 것: `docs/planning/cycle-12/director-proposal.md`, 내 사이클 11 기획안, `docs/PLAN.md` 사이클 11 결과, `public/index.html`(`#overlay`, `.panel`, `.side`, `#progcard`, `#ach`, `.medals`, `.slot`, `#players`), `public/js/main.js`(`showAch`·`updateAch`·`applySkin`·`kitPicker`·`showProgress`·`setOverlay`·키 입력), `public/js/hud.js`(동료 목록), `public/js/net.js`(`join` 메시지, 머리 위 이름표), `public/js/icons.js`(`GUN`, `gun()`), `public/js/weapons.js`(`setGunSkin`), `config.js`(`META.skins`). `docs/screenshots/`는 여전히 없어서 배치는 CSS 수치로 계산했다 **[실기 확인 필요]**.

## 1. 진단

### 1-1. 지금 "출격 준비"가 놓인 자리

| 사실 | 근거 |
| --- | --- |
| 진행 카드(`#progcard`)는 메뉴 오른쪽 열 `.side`(폭 340px, 최대 32vw) 안에 있다. 한 판 이상 한 사람에게는 계급 막대 → 다음 해금 → 가까운 훈장 3개 → 출격 준비(슬롯 2개 + 무기 색)가 한 카드에 쌓인다 | `showProgress('menu')`, `.vet` 규칙이 조작표를 숨김 |
| 출격 준비는 브라우저 기본 `<select>` 세 개다. 잠긴 항목은 `(계급 6)` 꼬리표가 붙은 비활성 옵션이다. 색은 **이름만** 보이고 색 자체는 보이지 않는다 | `kitPicker()` |
| 무기 색은 지금 **모든 무기 공통 하나**다. '숙련 금장'을 고르면 숙련 3단계가 아닌 무기는 기본색으로 돌아간다. 이 사실이 화면 어디에도 적혀 있지 않다 | `applySkin()`의 `mastery` 분기 |
| 게임 속 색은 고른 색 × 0.55로 어둡게 칠해지고, 금속·유리 재질은 칠하지 않는다 | `setGunSkin()`의 `multiplyScalar(0.55)`, `weapons.js` 159행 |

→ 보관함이 생기면 "무기 5종 × 색 23종 + 칭호 17 + 처치 연출 + 슬롯 2"를 다뤄야 한다. 340px 카드 안의 `<select>`로는 **색을 눈으로 비교할 수도, 잠긴 물건의 얻는 곳을 적을 수도 없다.** 전체 화면 패널이 필요하다는 총괄 판단에 동의한다.

### 1-2. 메뉴 화면 틀

- `#overlay`는 `.panel`(460px)과 `.side`(340px)를 좌우로 벌린 flex이고 좌우 여백이 7vw다. 1280px에서 쓸 수 있는 폭은 약 1,100px이다.
- 배경 그라데이션은 오른쪽으로 갈수록 투명해진다(`rgba(5,8,13,.4)`). 전체 화면 패널을 이 위에 그리면 오른쪽 절반의 글자가 3D 배경과 겹친다. **보관함은 자기 배경(불투명 0.94 이상)을 가져야 한다.**
- 메뉴에서 Esc는 지금 아무 일도 하지 않는다(키 입력이 `G.mode !== 'playing'`이면 Enter만 받고 끝난다). 보관함의 Esc 닫기는 새 처리로 넣어야 하고, 기존 동작과 부딪치지 않는다.

### 1-3. 판 도중 알림 자리

- 훈장 알림 `#ach`는 왼쪽 위(협동이면 동료 목록 아래 124px)에 3.2초 뜬다. 막 맞았거나(1.5초) 체력 35% 미만이면 미룬다. 줄은 하나이고 **합치는 규칙은 구현되지 않았다** — 사이클 11 안 3의 "3개 이상이면 한 줄로"는 빠졌다.
- 보스 웨이브 클리어 순간에는 이미 웨이브 클리어 배너, 특성 카드, 훈장 몇 개(첫 보스 등)가 한꺼번에 터진다. 여기에 드롭(40%)이 더해지면 **훈장 3개 + 드롭 1개 = 줄 4개, 약 13초**가 왼쪽 위에 이어진다. 합치는 규칙이 이제는 필요하다.

### 1-4. 결과 화면의 세로 여유

- 결과 화면 오른쪽 카드는 계급 막대 → XP 내역(최대 8줄 격자) → 이번 판 훈장 칩 → 다음 해금 → 숙련 줄 → 가까운 훈장 2개다. 10웨이브 판이면 훈장 칩이 두 줄로 넘어간다. 드롭 칩을 **새 줄로** 더하면 720p에서 넘칠 가능성이 높다 **[실기 확인 필요]**. 칩은 훈장과 같은 줄(`.medals`)에 이어 붙이고, 그 대신 다른 것을 줄여야 한다.

### 1-5. 협동 동료 목록과 이름

- 동료 목록은 `이름 — 점수` 한 줄이다(`hud.js` 161~162행). 이름은 그대로 `innerHTML`에 들어간다.
- 접속 메시지 `join`은 `name`, `room`만 보낸다. 머리 위 이름표(`nameSprite`)도 이름만 그린다.
- 칭호를 **자유 문자열로 보내면** 다른 사람이 아무 글자나 칭호처럼 띄울 수 있다. 칭호는 **id로 보내고 받는 쪽이 자기 표에서 이름을 찾아야 한다.**

### 1-6. 수집 탭의 확률 표기 함정

총괄 초안의 예시 "보스 웨이브 클리어 40%"를 미보유 물건 칸에 그대로 쓰면, 플레이어는 "이 물건이 40%로 나온다"로 읽는다. 실제로 특정 일반 물건이 보스 웨이브 한 번에 나올 확률은 40% × 70% × 1/10 ≈ **2.8%**다. 표기를 둘로 나눠야 한다: **드롭이 일어날 확률(사건별)**과 **드롭이 이 물건일 확률(물건별)**.

## 2. 화면 설계

### 2-1. 메뉴 진행 카드와 보관함 단추 — 출격 준비를 옮긴다

**판단: 고르는 일은 보관함으로 옮기고, 메뉴에는 "무엇을 들고 나가는지"만 한 줄로 남긴다.**

- 지참품은 판의 초반을 바꾸는 유일한 선택이라, 출격 직전에 **보여야** 한다. 그러나 **고르는 일**은 판마다 하지 않는다. 그러니 읽기 전용 요약은 메뉴에, 선택 상자는 보관함에 둔다.
- 무기 색 선택 상자는 메뉴에서 **뺀다**(무기별로 바뀌어 한 칸에 담을 수 없다).
- 가까운 훈장 3개 → **2개**로 줄여 단추 자리를 만든다. 훈장 전체는 보관함 훈장 탭에 있다.

```
┌ 진행 ───────────────────────────────────┐
│ ⬢5  병장                                 │
│     410 XP · 다음 계급까지 140            │
│ ██████████████▒▒░░░░░░                   │
│ ★ 계급 6: 사막 색 · 하사 칭호               │
│ 가까운 훈장                       12 / 24 │
│  헤드샷 누적   ▓▓▓▓▓▓▓▓░░          8 / 10 │
│  보급품 5회    ▓▓▓▓▓▓░░░░          3 / 5  │
│ 출격 준비                                 │
│  [＋] 구급 주사 1개 · [●] 수류탄 +1        │
│ ┌──────────────────────────────────────┐ │
│ │ 보관함 (I)                   새로 2  │ │
│ └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

- 단추는 카드 폭 전체, 높이 40px, 테두리 호박색. 새 물건이 있으면 오른쪽에 `새로 2` 글자 꼬리표(초록 바탕 검은 글자). **점만 찍지 않는다** — 색을 못 보는 사람도 읽게.
- 출격 준비 줄의 지참품을 누르면 보관함 장착 탭의 해당 슬롯으로 바로 연다.
- **한 판도 하지 않은 사람에게는 보관함 단추를 숨긴다.** 사이클 11의 `vet` 규칙과 같다. 처음 5분의 메뉴는 맵·난이도·솔로 플레이·조작표만으로 충분하다. 첫 판이 끝나 메뉴로 오면 단추가 나타난다.
- 단축키 `I`: 메뉴에서만. 닉네임·방 이름 입력 중에는 받지 않는다(기존 `INPUT` 가드 그대로).
- 보관함은 **메뉴에서만** 연다. 일시정지·결과 화면에서는 열지 않는다. 협동 일시정지는 게임이 계속 흐르고, 결과 화면은 Enter 재시작이 가장 중요한 동작이라서다.

### 2-2. 보관함 공통 틀 (1280×720 기준)

`#overlay`에 `m-vault` 모드를 더한다. `.panel`과 `.side`를 숨기고 `#vault` 하나를 화면 가운데 띄운다.

- 크기: 폭 `min(1120px, 100vw - 64px)`, 높이 `min(640px, 100vh - 48px)`. 1280×720에서 1,120 × 640. 배경 `rgba(8,12,18,.96)`, 기존 `.card`와 같은 모서리 잘림(`--cut`).
- 세로 배분: 머리줄 52 + 본문 532 + 조작 안내줄 28 + 안쪽 여백 28 = 640.
- 본문은 **왼쪽 목록(약 680px) | 오른쪽 상세(약 380px)** 두 칸. 네 탭이 모두 같은 틀이라 "왼쪽에서 고르고 오른쪽에서 읽는다" 한 가지만 익히면 된다.
- 1000px보다 좁은 창에서는 상세 칸을 본문 아래 띠(높이 150px)로 내린다.

```
┌──────────────────────────────────────────────── 1120 × 640 ─────────────────────────────────────────────────┐
│ 보관함    [1 장착]  [2 수집 9/23  새로 2]  [3 훈장 12/24]  [4 특성 6/8]                       [닫기 · Esc] │ 52
├────────────────────────────────────────────────────────────────────┬────────────────────────────────────────┤
│                                                                    │                                        │
│                      왼쪽: 목록 / 격자 (680)                        │         오른쪽: 상세 (380)              │ 532
│                                                                    │                                        │
├────────────────────────────────────────────────────────────────────┴────────────────────────────────────────┤
│ ↑↓ 고르기   ← → 목록과 상세 오가기   Enter 장착·켜기   1~4 탭   Esc 닫기                                     │ 28
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**조작**

| 입력 | 동작 |
| --- | --- |
| `I` (메뉴) / 보관함 단추 | 연다. 처음 열면 장착 탭. 그 뒤로는 마지막에 본 탭. 새 물건이 있으면 그 물건이 있는 탭 |
| `Esc` / `닫기` 단추 | 닫고 메뉴로. 포커스는 보관함 단추로 돌아간다 |
| `1`~`4` | 탭 이동. 마우스로 탭 클릭 |
| `↑ ↓` | 왼쪽 목록에서 고르기. 격자 탭에서는 `↑ ↓ ← →` 모두 칸 이동 |
| `→` / `←` | 장착 탭에서 왼쪽 슬롯 목록 ↔ 오른쪽 선택지 칩 오가기 |
| `Enter` / `Space` / 클릭 | 장착, 켜기·끄기 |
| 마우스 올리기 | 상세 칸을 그 물건으로 바꾼다(클릭하지 않아도 읽힘). 클릭해야 장착된다 |

- 장착은 **누르는 즉시 저장**한다. "저장" 단추는 두지 않는다. 지금의 `change` → `saveMeta()`와 같은 방식이다.
- 포커스 테두리는 호박색 2px로 늘 보인다. 탭 키(Tab)는 브라우저 기본 순서를 따른다.
- 패널 바깥 클릭으로 닫지 않는다. 전체 화면이라 바깥이 거의 없고, 실수로 닫힐 이유만 생긴다.

**등급 표기 (색만으로 구분하지 않는다)**

| 등급 | 테두리 | 모양 표시 | 글자 |
| --- | --- | --- | --- |
| 일반 | 밝은 회색 `#c9d2dc` 1px | `■` | 일반 |
| 희귀 | 하늘색 `#4fd8ff` 2px | `◆` | 희귀 |
| 전설 | 보라 `#c79bff` 2px + 바깥 은은한 빛 | `✦` | 전설 |
| 계급·숙련 | 호박색 점선 1px | `▲` | 계급 / 숙련 |

호박색은 훈장과 계급에 이미 쓰고 있어서, 드롭 등급에는 쓰지 않는다. 전설의 빛은 `prefers-reduced-motion`이면 움직이지 않는다(빛 자체는 정지 상태로 남긴다).

### 2-3. 장착 탭

```
┌ 왼쪽: 슬롯 (380)                              ┬ 오른쪽: 선택지 (700) ───────────────────────────────────┐
│ 무기 색                                       │ 소총 · 무기 색                                           │
│ ▸ [▬▬소총▬▬]   소총     청록      새로        │ ┌─────────────────────────────────────┐                  │
│   [▬▬샷건▬▬]   샷건     기본                  │ │                                     │                  │
│   [▬▬저격▬▬]   저격총   사막                  │ │     소총 실루엣 360 × 144 (청록)      │                  │
│   [▬권총▬]     권총     기본                  │ │                                     │                  │
│   [▬▬로켓▬▬]   로켓     기본                  │ └─────────────────────────────────────┘                  │
│ ─────────────────────────────                 │ ■ 청록 · 일반 · 11월 3일 보스 웨이브에서 얻음              │
│ 칭호            명사수                         │                                                          │
│ 처치 연출        기본                          │ 가진 색 7                                                 │
│ ─────────────────────────────                 │ [기본] [▲사막] [▲올리브] [■청록 새로] [■잿빛] [◆청동] [✦…] │
│ 보급 슬롯 1      구급 주사 1개                  │                                                          │
│ 보급 슬롯 2      수류탄 +1                     │ [ 이 색을 모든 무기에 적용 ]                               │
│                                               │ 아직 없는 색 16개 — 얻는 곳은 수집 탭(2)에서               │
└───────────────────────────────────────────────┴──────────────────────────────────────────────────────────┘
```

- 왼쪽 슬롯 행 높이: 무기 5행 × 48px, 나머지 4행 × 40px, 구분선 2개 → 약 430px. 본문 532px 안에 들어간다.
- 무기 행의 작은 실루엣(72 × 28)은 **장착한 색으로 칠한다.** 슬롯 목록만 봐도 다섯 자루의 현재 모습이 한눈에 보인다.
- 로켓은 보급으로만 얻는 무기지만 숙련도가 있으므로 행을 둔다. 이름 옆에 `보급 무기` 작은 글자.
- `이 색을 모든 무기에 적용`: 사이클 11까지 색이 하나였던 사람, 무기별로 고를 생각이 없는 사람을 위한 한 번 누르기. 이 단추가 있으면 "무기별 색"이 일을 늘리지 않는다.
- '숙련 금장'은 숙련 3단계가 아닌 무기에서는 칩을 흐리게 두고, 상세에 `샷건 숙련 3단계에서 열림 · 412 / 600`. 지금처럼 고를 수 있는데 조용히 기본색이 되는 일을 없앤다.
- **장착 탭에는 가진 것만 보인다.** 잠긴 23개를 여기 다 깔면 고르는 화면이 아니라 구경하는 화면이 된다. 잠긴 것은 개수 한 줄로 수집 탭에 넘긴다.
- 칭호 행을 고르면 오른쪽은 칭호 목록(계급 칭호 · 훈장 칭호 · 드롭 칭호 세 묶음, 가진 것만)과 맨 위에 `표시 안 함`. 상세에 **동료에게 보이는 모습 미리보기** 한 줄: `명사수 철수 — 1,240`.
- 칭호 기본값은 `계급 칭호(자동)` — 계급이 오르면 따라 바뀐다. 아무것도 고르지 않은 사람도 무언가 보이고, 일부러 고른 칭호는 고정된다.
- 처치 연출 행: 기본 · 청록 · 금색 칩. 상세에 파편 아이콘을 그 색으로 그리고 `내 화면에서만 보입니다`.
- 보급 슬롯 행: 지금의 지참품 4종을 칩으로. 다른 슬롯에 든 것은 흐리게 `슬롯 2에 있음`. 잠긴 것은 `계급 5에 열림`.

**3D 미리보기 없이 SVG 실루엣으로 충분한가 — 충분하다. 단, 세 가지를 맞춘다.**

1. **실루엣 색을 게임과 같은 밝기로**: 게임은 고른 색 × 0.55로 칠한다. 실루엣도 같은 계산값으로 칠한다. 원래 색으로 칠하면 메뉴에서 밝은 청록을 골랐는데 게임에서는 탁한 청록이 보여 "색이 다르다"가 된다. 어두운 색(올리브 × 0.55)이 어두운 배경에 묻히지 않게 실루엣에 `rgba(255,255,255,.28)` 1px 외곽선을 둔다.
2. **등급별 질감 표현**: `gun()`은 경로 하나짜리 실루엣이라 부품별 색은 못 낸다. 대신
   - 일반: 단색 채움.
   - 희귀(금속 광택): 같은 색 위에 비스듬한 흰 띠 그라데이션(투명도 0 → 0.35 → 0) 한 줄. "번쩍이는 금속"으로 읽힌다.
   - 전설(발광 무늬): 단색 + 같은 색의 바깥 빛(`drop-shadow(0 0 6px)`) + 몸통 가운데 가는 밝은 선.
3. **색 칩**: 32 × 32 사각. 일반은 단색, 희귀는 대각선 반으로 나눠 아래쪽을 밝게, 전설은 칩 안에 작은 `✦`. 칩 아래에 이름은 쓰지 않고(칩이 7개 넘으면 줄이 넘친다), 마우스 올리기·포커스 때 상세 칸에 이름·등급·얻은 날이 바로 나온다. 칩에도 `title`과 `aria-label`로 이름을 단다.

3D 미리보기는 비용(메뉴 뒤 장면에 무기 모델 띄우기, 카메라·조명)에 비해 이득이 작다. 실루엣과 실제 게임 색이 어긋나는지만 검증(4장)으로 확인한다. 금속·유리 부품이 칠해지지 않는다는 점 때문에 실제 총은 실루엣보다 "덜 칠해져" 보인다. 상세 칸 맨 아래에 `총열·조준경 같은 금속 부품은 칠하지 않습니다` 한 줄을 둔다.

### 2-4. 수집 탭

- 칸 64 × 64, 간격 8px. 한 줄 10칸 = 712px라 일반 10개가 한 줄에 들어간다. 머리 문구 3줄(약 84px) + 등급 줄 4개 × 88px(칸 64 + 등급 이름 24) = 436px. 본문 532px 안.
- 칸 안 그림: 무기 색은 소총 실루엣을 그 색으로(아직 없으면 그 색을 30% 투명도 + 자물쇠 아이콘), 칭호는 칭호 글자를 작은 꼬리표 모양으로, 처치 연출은 파편 아이콘을 그 색으로.
- **아직 없는 것도 이름과 모습을 보여 준다.** 무엇을 노리는지 알아야 다시 할 이유가 된다. 예외는 전설 2개 중 아직 없는 것: 실루엣과 `✦ ?`만 보이고 이름은 감춘다. "무엇이 나올지 모르는" 기대가 남는 자리를 하나만 둔다.
- 새로 얻은 칸 오른쪽 위에 `새로` 글자 꼬리표.

**확률 표기 규칙 (진단 1-6)**

- 머리줄에 **사건별 확률**: `보스 웨이브 클리어 40% · 보급품 줍기 10%`. 이 숫자는 물건마다 같으므로 한 번만 쓴다.
- 상세 칸에 **물건별 확률**: `드롭이 나오면 이것일 확률 약 6%`. 계산은 (그 등급 가중치 ÷ 아직 없는 물건이 남은 등급들의 가중치 합) ÷ 그 등급의 아직 없는 물건 수, 소수 없이 반올림, 1% 미만은 `1% 미만`. 괄호 안에 계산 근거 한 줄(`희귀 25% ÷ 아직 없는 희귀 4개`).
  - 처음(아무것도 없을 때) 일반 7%, 희귀 약 4%, 전설 2.5%(→ `약 3%`)다. 모을수록 남은 물건의 확률이 오른다. **중복 방지가 화면에서 보이는 순간**이다.
  - 등급을 다 모았을 때 넘기는 방식(남은 등급끼리 가중치를 다시 나누는지)은 시스템 기획자가 확정해 주면 같은 식으로 표기한다.
- 물건별 확률에 사건 확률(40%)을 곱한 "보스 웨이브 한 번에 2.8%" 같은 숫자는 쓰지 않는다. 숫자가 둘 겹치면 계산하는 사람만 읽는다.
- 계급·숙련 칸은 확률 대신 조건과 진척: `계급 8에 열림 · 지금 계급 5 (410 / 850 XP)`, `숙련 3단계 무기에서 열림 · 가장 가까운 무기: 소총 412 / 1000`.
- 18종을 다 모으면 머리줄을 `드롭 수집 완료 — 이제 드롭은 15 XP로 바뀝니다`로 바꾼다.

**빈 상태**(첫 판 직후, 드롭 0개): 격자 위에 한 줄
`아직 드롭으로 얻은 물건이 없습니다. 5웨이브 보스를 쓰러뜨리거나 보급품을 주우면 무언가 떨어질 수 있습니다.`

### 2-5. 훈장 탭


- 칸 220 × 52: 단계 글자(입문·초급…) 10px + 이름 13px + 진척 막대 4px. 3열 × 8행 = 약 450px.

- **상세 칸의 "보상" 묶음이 이 탭의 핵심이다.** 지금 상급 이상 훈장은 XP만 줘서(총괄 진단 1-2) 따야 할 이유가 안 보였다. 이번 사이클부터는 같은 훈장이 희귀 확정, 칭호, 해금 특성(A안)을 연다. 이 셋을 한 자리에 적는다.
  - 보상 줄 예: `+80 XP` / `◆ 희귀 물건 1개 확정` / `칭호 '강철'` / `특성 '숨 고르기' 열림`
- 달성한 훈장은 `11월 3일 달성`. 사이클 11 이전에 딴 것은 날짜가 없으면 `달성`만.
- 필터 단추 셋: `전체` `달성` `진행 중`. 기본은 `전체`.

- 행 높이 52px × 8 + 머리 문구 약 110px = 526px. 빠듯하다. 넘치면 설명 줄은 상세 칸으로 옮기고 행을 36px로 줄인다 **[실기 확인]**.
- **스위치 문구는 "켜짐/꺼짐"이 아니라 결과를 적는다**: `● 카드에 나옴` / `○ 카드에서 뺌`. "끄기"는 "효과를 잃는다"로 읽힐 수 있다. 실제로 하는 일은 "카드 더미에서 뺀다"이니 그대로 말한다.
- 상단 설명 두 줄을 탭을 열 때마다 보이게 둔다. 끈 특성을 다시 켤 수 있다는 것, 그리고 **왜 끄는지**(원하는 카드를 더 자주 보려고)를 같이 적어야 끄는 행동이 손해처럼 느껴지지 않는다.
- `지금 카드 종류 일반 10 · 희귀 7`: 스위치를 누르면 숫자가 바로 바뀐다. 확률 %는 쓰지 않는다. 확률은 모의 실험값이라 화면에서 정확히 계산해 보여 주기 어렵고, 종류 수만으로 방향은 충분히 전달된다.
- 잠긴 특성은 조건과 진척(`보급품 누적 5회 · 3 / 5`). 스위치 자리에 `잠김`.
- 무기 전용 특성 묶음 머리에 `그 무기를 든 동안에만 작동` 한 줄. 상세에는 `이번 판에서 소총으로 10명을 처치한 뒤부터 카드에 나옵니다`.
- 오른쪽 숙련표: 5무기 × 3단계. 다음 단계는 진척 막대, 지난 단계는 `✓`. 표 아래에 단계별 보상 3줄. 지금은 숙련도가 결과 화면 한 줄(`masteryLine`)에만 보이는데, 처음으로 "어느 무기를 키우면 무엇이 열리는지"가 한 표에 모인다.

**판 안 특성 카드에도 같은 말을 쓴다** (보관함 밖이지만 같은 정보라서 같이 정한다)
- 해금 특성 카드: 이름 위에 작은 꼬리표 `해금`.
- 무기 전용 특성 카드: 이름 위에 `소총 전용`, 설명 끝에 `소총을 든 동안에만`. 고른 뒤 다른 무기를 들면 특성 줄(`#perklist`)의 그 아이콘을 흐리게(투명도 0.4) 해서 "지금은 작동하지 않음"이 보이게 한다.

### 2-7. 드롭 연출

**판 도중: 훈장 알림과 같은 자리, 같은 미루기 규칙**

`#ach` 하나를 같이 쓴다. 줄(`achQueue`)도 하나다. 훈장과 드롭이 다른 자리에 뜨면 왼쪽 위에서 두 상자가 겹친다.

```
┌──────────────────────────────────────┐        ┌──────────────────────────────────────┐
│ ★  훈장 · 상급                  +80 XP│        │ ▬▬  보관함 · ◆ 희귀                   │  ← 왼쪽 테두리 하늘색
│    강철                               │        │ (총)  청동                             │
│    피해 100 미만으로 5웨이브 클리어     │        │      무기 색 · 메뉴의 보관함에서 장착    │
└──────────────────────────────────────┘        └──────────────────────────────────────┘
```

- 왼쪽 그림: 무기 색이면 소총 실루엣(40 × 16)을 그 색으로, 칭호면 꼬리표 아이콘, 처치 연출이면 파편 아이콘.
- 작은 글자: `보관함 · ■ 일반` / `◆ 희귀` / `✦ 전설`. 왼쪽 테두리는 등급 색. 오른쪽 숫자 칸(`em`)은 비운다.
- 셋째 줄은 분류와 `메뉴의 보관함에서 장착`. **판 도중에 바로 바뀌지 않는다는 것**을 적는다. 사이클 11 안 3의 "다음 판부터" 원칙과 같다.
- 훈장이 준 확정 드롭이면 셋째 줄을 `무기 색 · 강철 훈장 보상`으로 바꿔 둘이 이어진 사건이라는 것을 보여 준다. 줄에서는 그 훈장 바로 뒤에 둔다.
- 미루기: 지금 규칙 그대로(막 맞았거나 1.5초, 체력 35% 미만). 보급품 드롭(10%)은 전투 중에 일어나니 미뤄지는 일이 많다. 그래도 웨이브 클리어 때 `flushAch`가 비운다.
- **합치기(새로 구현)**: 줄에 4개 이상 쌓이면 남은 것을 하나로 합친다. `보관함에 2개 · 훈장 2개 — 결과 화면에서 확인`. 보스 웨이브 클리어에 훈장 3개 + 드롭이 겹치면 13초 대신 약 6.4초로 끝난다. 전설은 합치지 않고 따로 띄운다(가장 드문 순간이다).
- 소리: 일반·희귀는 지금 훈장 소리(`sfx.perk`). 전설만 다른 소리 하나. 새 소리를 늘리는 것은 전설 하나뿐이다.
- 수집을 다 끝낸 뒤의 드롭: `보관함 완성 · 대신 +15 XP` (작은 글자 `보관함`, `em`에 `+15 XP`).

**결과 화면: 훈장 칩 줄에 이어 붙인다**

```
이번 판에서 얻은 것
⬢5 병장 ███████▒▒░░   +86 XP
 ...XP 내역...
[★ 첫 보스 +40] [★ 강철 +80] [◆ 청동 · 무기 색] [■ 금색 · 처치 연출]
새 물건은 메인 메뉴 → 보관함에서 장착합니다
★ 계급 6: 사막 색 · 하사 칭호
```

- 드롭 칩은 `.medal`과 같은 크기, 테두리만 등급 색, 앞에 등급 모양(`■◆✦`). 훈장 칩 **뒤에** 같은 줄로 이어 붙인다. 새 줄을 만들지 않는다.
- 드롭이 있는 판에만 칩 줄 아래 안내 한 줄. 안내는 11.5px 회색.
- **720p 세로 확보**: 드롭이나 훈장 칩이 6개를 넘으면 `가까운 훈장` 2개를 1개로 줄인다. 그래도 넘치면 숙련 줄(`masteryLine`)을 뺀다. 숙련은 이제 보관함 특성 탭에 표로 있다.
- 칩은 누를 수 없다. 결과 화면에서 보관함으로 가는 길을 만들면 Enter 재시작 흐름에 갈래가 생긴다. 칩은 "얻었다"만 말하고, 장착은 메뉴에서 한다.
- `XP 내역`에 수집 완료 이후 전환분이 있으면 `수집 완료 보너스 15` 한 줄.
- 다음 목표 줄(`#nextgoal`)은 그대로 훈장 기준. 드롭은 운이라 "다음 목표"가 될 수 없다.

**새 물건 표시(배지)**

| 자리 | 표시 | 지워지는 때 |
| --- | --- | --- |
| 메뉴 보관함 단추 | `새로 N` (N = 아직 안 본 물건 수) | N이 0이 되면 |
| 보관함 탭 이름 | `수집 9/23  새로 2` | 그 탭의 새 물건을 다 봤을 때 |
| 장착 탭 슬롯 행 | 새 색이 든 무기 행에 `새로` | 그 행을 골랐을 때 |
| 수집 탭 칸 | 칸 오른쪽 위 `새로` | 그 칸에 포커스·마우스가 갔거나, 탭을 연 채 3초가 지났을 때 |

- 물건 하나하나 지운다. 탭을 한 번 열었다고 전부 지우면, 장착 탭에서 샷건 색이 새로 생긴 걸 모르고 지나친다.
- 데이터: `inv.fresh: [id, …]` 한 줄이면 된다(시스템 기획자 확인 필요). 얻을 때 넣고 볼 때 뺀다.
- 계급으로 새로 열린 색·칭호도 같은 규칙으로 `새로`를 붙인다. 계급 보상은 `owned`에 넣지 않는다는 총괄 원칙(C-3)이 있으니, "본 적 있는 계급 보상"만 따로 기억한다(`inv.seenRank: 6` 같은 숫자 하나).

### 2-8. 칭호가 협동 동료 목록에 보이는 모습

```
┌───────────────────────────────┐
│ 명사수  철수 (나) — 1,240       │   ← 칭호 11px, 호박색 70% / 이름 13px 흰색
│ 강철    영희 — 980             │
│ 병장    Player — 410           │   ← 계급 칭호(자동)
│ 민수 — 120                     │   ← 표시 안 함
└───────────────────────────────┘
```

- 칭호는 이름 **앞**, 작은 글자. "명사수 철수"처럼 호칭으로 읽힌다. 뒤에 붙이면 점수와 섞인다(`철수 명사수 — 1,240`).
- 드롭 희귀 칭호는 하늘색 글자로 구분한다. 계급·훈장 칭호는 호박색.
- **id로 보낸다**: `join` 메시지에 `title: 'title-ghost'`. 받는 쪽이 자기 표에서 이름을 찾고, 모르는 id(버전 차이)면 칭호 없이 이름만. 자유 문자열을 그리지 않는다(진단 1-5).
- 폭: 가장 긴 칭호(`포격 사냥꾼`, 5글자) + 이름 16자 + 점수에서 약 300px. 지금 `#ach`의 위치 계산(동료 목록 아래 124px)은 줄 수 기준이라 폭이 늘어도 겹치지 않는다.
- **머리 위 이름표(`nameSprite`)에는 넣지 않는다.** 전투 중 시야 안에 글자가 늘어난다. 이름표는 "저 사람이 누구인가"만 말하면 된다.
- **순위표에는 이번에 넣지 않는다.** 순위표 줄(340px)에 이미 이름 + `협동`·`어려움` 꼬리표 + 웨이브 + 점수가 있다. 칭호까지 넣으면 이름이 잘린다. 서버 점수 저장 형식(`/api/scores`)도 바꿔야 한다. 협동 목록에서 반응을 본 뒤 다시 다룬다. 총괄 초안 C-1의 "순위표에 표시"는 빼자고 제안한다.

| 판 도중 알림 | 시나리오: 피해를 받는 중에 보급품 드롭 → 표시 안 됨 → 1.5초 뒤 표시. 보스 웨이브 클리어에 훈장 3 + 드롭 1 → 합친 한 줄. 전설은 따로 | 위와 같음. 배너·특성 카드와 겹치지 않는 스크린샷 |

## 5. 다른 기획자에게 요청하는 것

- **시스템**: `inv.fresh`(새 물건 목록)와 `inv.seenRank`(본 계급 보상) 필드. 등급을 다 모았을 때 확률을 넘기는 정확한 규칙(화면 확률 계산과 같은 식이어야 함). 판 기록 `meta`에 `drops`, `perksOff`, `vault` 필드.
- **시스템**: 특화 특성도 켜고 끄기 대상인지. 이 안은 대상이라고 가정했다(한 탭에서 같은 스위치로 다루는 편이 덜 헷갈린다).
- **총괄**: 칭호를 순위표에 넣는 부분(C-1)을 이번 범위에서 빼는 것 (2-8).

## 7. 검토했지만 뺀 것

- **3D 무기 미리보기**: 메뉴 뒤 장면에 모델·카메라·조명을 따로 세워야 한다. 실루엣을 게임과 같은 밝기로 칠하면 고르는 데 필요한 정보는 충분하다(2-3).
- **결과 화면 칩을 눌러 바로 장착**: Enter 재시작 흐름에 갈래가 생긴다. 메뉴의 `새로` 배지로 충분하다.
- **판 안(일시정지)에서 보관함 열기**: 협동 일시정지는 시간이 흐르고, 장착 변경을 판 도중에 반영하면 "다음 판부터" 원칙이 깨진다.
- **머리 위 이름표에 칭호**: 전투 중 시야의 글자를 늘린다.
- **물건별 확률에 사건 확률을 곱한 숫자**(보스 웨이브당 2.8%): 숫자 두 겹은 읽히지 않는다. 사건별은 머리줄 한 번, 물건별은 상세 칸 한 번.
- **특성 탭에 "원하는 카드가 나올 확률 %"**: 모의 실험값이라 켜고 끌 때마다 정확히 계산해 보여 주기 어렵다. 종류 수로 방향만 전달한다.
